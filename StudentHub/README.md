# StudentHub — Student Resource Website

StudentHub is a simple, responsive educational website created for **Web Engineering Assignment 1**. It helps students explore study techniques, programming foundations, web development, career preparation, productivity habits, and learning resources.

## Features

- 10 separate HTML pages
- Shared CSS stylesheet for consistent styling
- Navigation links between pages
- Responsive layout for desktop, tablet, and mobile screens
- Learning cards, resource links, FAQ content, and a sample contact form
- Built with HTML5 and CSS3 only — no JavaScript or backend

## Pages

1. **Home** (`index.html`) — introduction and topic overview
2. **About** (`about.html`) — website purpose and approach
3. **Study Tips** (`study-tips.html`) — study and revision techniques
4. **Programming** (`programming.html`) — programming fundamentals and learning path
5. **Web Development** (`web-development.html`) — HTML, CSS, accessibility, and responsive design
6. **Career Guidance** (`career-guidance.html`) — CV, portfolio, projects, and interview preparation
7. **Study Resources** (`resources.html`) — links to educational websites and documentation
8. **Productivity** (`productivity.html`) — planning and time-management suggestions
9. **FAQs** (`faqs.html`) — answers to common questions
10. **Contact** (`contact.html`) — sample contact details and a demonstration form

## Technology Used

- HTML5 for page structure and content
- CSS3 for layout, colors, typography, cards, navigation, and responsive design
- Git and GitHub for version control and hosting

## Website Architecture

Each page is stored in a separate HTML file in the project root. All pages link to the same `style.css` file to keep the design consistent and make maintenance easier. The main navigation uses ordinary HTML anchor links to move between pages. CSS media queries adjust the layout for smaller screens. No JavaScript, database, or server-side code is used.

## Run Locally

1. Download or clone this repository.
2. Keep all HTML files and `style.css` in the same folder.
3. Open `index.html` in a web browser.

## Deploy on GitHub Pages

1. Create a GitHub repository named `studenthub-website`.
2. Upload all project files and commit them to the `main` branch.
3. Open the repository's **Settings**.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site. The live URL will appear in the Pages section.

## Important Note

The contact form is a front-end demonstration only. Because the project intentionally uses HTML and CSS without a backend or form service, it does not deliver messages.
