Web Development

Discover how HTML and CSS work together to create websites.

HTML

HTML: Page structure

HTML defines the content of a page, including headings, paragraphs, links, images, lists, and forms.

CSS

CSS: Page presentation

CSS controls colors, typography, spacing, layout, borders, and how a website adapts to different screen sizes.

UX

Usability and accessibility

Use clear navigation, readable text, meaningful link labels, and sufficient color contrast to help visitors use the website.

WEB

Responsive design

Responsive layouts adjust to phones, tablets, and desktop screens. CSS media queries help change layouts for smaller displays.

Your first website checklist

  • Create a separate HTML file for each page.
  • Use semantic elements such as header, nav, main, and footer.
  • Connect a shared stylesheet with a link element.
  • Check every navigation link before publishing.
  • Test the site on a narrow screen and a desktop screen.
For this StudentHub assignment, all pages use plain HTML and one shared CSS file. JavaScript is not required.
