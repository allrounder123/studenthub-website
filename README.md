
# StudentHub — Student Resource Website

StudentHub is a responsive educational website created for Web Engineering Assignment 1. It provides students with study tips, programming guidance, web development information, career advice, productivity suggestions, and learning resources.

## Features

- 10 separate HTML pages
- Shared CSS stylesheet
- Navigation between all pages
- Responsive design for desktop and mobile
- Educational content and external learning resources
- Built using HTML5 and CSS3 only
- No JavaScript or backend

## Pages

1. Home
2. About
3. Study Tips
4. Programming
5. Web Development
6. Career Guidance
7. Study Resources
8. Productivity
9. FAQs
10. Contact

## Technologies Used

- HTML5
- CSS3
- GitHub
- GitHub Pages

## Website Architecture

The website consists of 10 separate HTML files and one shared CSS file. Each HTML file represents a different page. All pages use the same stylesheet to maintain a consistent design. Navigation is implemented using HTML anchor links. CSS media queries make the layout responsive on different screen sizes.

JavaScript, databases, and backend technologies are not used.

## How to Run

1. Download or clone the repository.
2. Keep all HTML files and style.css in the same folder.
3. Open index.html in a web browser.

## Deployment

The website is hosted using GitHub Pages.
